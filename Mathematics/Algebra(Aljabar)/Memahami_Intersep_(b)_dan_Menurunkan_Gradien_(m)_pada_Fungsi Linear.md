# 📘 Catatan Aljabar Dasar

## Memahami Intersep (b) dan Menurunkan Gradien (m) pada Fungsi Linear

---

# 🎯 1. Apa Itu Intersep?

Dalam persamaan garis:

```text
y = mx + b
```

Keterangan:

* **m** = gradien (kemiringan garis)
* **b** = intersep-y (*y-intercept*)

📌 **Intersep adalah titik potong garis dengan sumbu koordinat.**

Pada bentuk:

```text
y = mx + b
```

nilai **b** menunjukkan:

> Nilai y saat x = 0.

---

## ✨ Cara Mencari Intersep

Set nilai **x = 0**.

### Contoh

```text
y = 2x + 3
```

Substitusi:

```text
y = 2(0) + 3
```

```text
y = 3
```

Maka:

```text
Intersep-y = (0, 3)
```

Artinya garis memotong sumbu y pada titik **(0, 3)**.

---

## 💡 Makna Konsep Intersep

Intersep sering diartikan sebagai:

* Biaya awal
* Modal awal
* Saldo awal
* Nilai awal

tergantung konteks soal.

### Contoh

```text
f(x) = 5x + 20
```

Keterangan:

* x = jam penggunaan
* f(x) = total biaya

Interpretasi:

* Gradien m = 5 → biaya bertambah $5 setiap jam.
* Intersep b = 20 → saat penggunaan 0 jam, biaya sudah $20.

---

## ⚠️ Kesalahan yang Sering Terjadi

Banyak siswa mengira intersep adalah hasil akhir persamaan.

Contoh:

```text
y = 2x + 3
```

Angka **3** bukan hasil akhir.

Jika:

```text
x = 10
```

Maka:

```text
y = 2(10) + 3
```

```text
y = 23
```

* Intersep = 3
* Hasil akhir = 23

📌 Intersep adalah **nilai awal**, bukan selalu hasil akhir.

---

# 🎯 2. Apa Itu Menurunkan Gradien?

Dalam konteks fungsi linear:

> Menurunkan gradien berarti mencari atau memperoleh nilai gradien dari informasi yang diberikan.

Kata "menurunkan" di sini berarti:

* menemukan,
* menghitung,
* memperoleh.

Bukan berarti membuat gradien menjadi lebih kecil.

---

## 📐 Rumus Gradien

Jika diketahui dua titik:

```text
(x₁, y₁)
```

dan

```text
(x₂, y₂)
```

maka:

```text
m = (y₂ - y₁) / (x₂ - x₁)
```

---

## ✨ Contoh Menurunkan Gradien

Diketahui:

```text
(2, 5)
```

dan

```text
(6, 13)
```

Substitusi:

```text
m = (13 - 5) / (6 - 2)
```

```text
m = 8 / 4
```

```text
m = 2
```

Jadi gradien yang berhasil ditemukan adalah:

```text
m = 2
```

---

## 💡 Makna Gradien

Gradien menunjukkan:

> Seberapa besar perubahan nilai y ketika x berubah satu satuan.

Contoh:

```text
m = 2
```

Artinya:

* Jika x naik 1,
* maka y naik 2.

---

# 🎯 3. Hubungan Gradien dan Intersep

Dalam bentuk:

```text
y = mx + b
```

* **m** menentukan kemiringan garis.
* **b** menentukan posisi awal garis pada sumbu y.

### Contoh

```text
y = 3x + 4
```

Interpretasi:

* Gradien = 3
* Intersep = 4

Artinya:

* Setiap x bertambah 1, y bertambah 3.
* Saat x = 0, nilai awal y = 4.

---

# ⚠️ Menurunkan Gradien ≠ Turunan Kalkulus

Sering terjadi kebingungan antara dua istilah berikut:

| Istilah              | Arti                                   |
| -------------------- | -------------------------------------- |
| Menurunkan gradien   | Mencari atau menghitung nilai gradien  |
| Turunan (Derivative) | Materi kalkulus tentang laju perubahan |

📌 Pada materi fungsi linear dasar, "menurunkan gradien" biasanya hanya berarti **menghitung nilai gradien dari data yang tersedia**.

---

# 📝 Ringkasan Cepat

### Intersep (b)

✅ Titik potong garis dengan sumbu y

✅ Nilai y saat x = 0

✅ Sering bermakna nilai awal

---

### Gradien (m)

✅ Kemiringan garis

✅ Menunjukkan perubahan y terhadap x

✅ Dicari menggunakan:

```text
m = (y₂ - y₁) / (x₂ - x₁)
```

---

### Bentuk Umum Fungsi Linear

```text
y = mx + b
```

Keterangan:

* m = gradien
* b = intersep

---

## 🧠 Intuisi Sederhana

Bayangkan biaya layanan:

```text
Biaya = (tarif per jam × jumlah jam) + biaya awal
```

Maka:

* Tarif per jam = gradien (m)
* Biaya awal = intersep (b)

Sehingga:

```text
y = mx + b
```

menjadi model hubungan antara **nilai awal** dan **laju perubahan**.
